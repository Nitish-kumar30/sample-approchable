# Website Footer — Documentation & Recommendations

**Prepared for:** AI Training Platform
**Target Audience:** Mid-level professionals & top management (5–20 years experience)
**Purpose:** Define footer structure, immediate additions, and future tool roadmap

---

## 1. Objective

The footer is often the first place experienced professionals and decision-makers look for credibility signals, enterprise options, and a direct way to contact the company — rather than exploring the full site. This document outlines what should be added to the footer now, and what can be planned for later as the platform grows.

---

## 2. Footer Structure — Add Right Away

These are items that can be implemented immediately using existing pages/content, or with minimal new content creation.

### 2.1 Company
| Item | Notes |
|---|---|
| About Us | Builds credibility with senior buyers |
| Careers | Signals stability and growth |
| Contact Us | Direct line for enterprise leads |

### 2.2 Product / Offering
| Item | Notes |
|---|---|
| Course Catalog / All Programs | Core navigation |
| Corporate / Enterprise Training | High priority — management audience often buys for teams |
| Pricing / Plans | Reduces friction for evaluators |

### 2.3 Tools
| Item | Notes |
|---|---|
| **Prompt Evaluator** | Already built — add link now |

> This column is being created now with one live tool, but is structured to scale as more tools are built (see Section 3).

### 2.4 Resources
| Item | Notes |
|---|---|
| Blog / Insights | Supports SEO and thought leadership |
| FAQs | Reduces support load |
| Case Studies (if available) | Strong trust signal for management buyers |

### 2.5 Support
| Item | Notes |
|---|---|
| Help Center | Self-serve support |
| Request a Demo / Talk to an Advisor | Important — this audience often prefers human contact over self-signup |

### 2.6 Legal & Compliance
| Item | Notes |
|---|---|

## 3. Tools — Build Later (Roadmap)

These are suggested tools to build and add to the **Tools** footer column over time. Grouped by theme and rough effort level.

### 3.1 Prompt & AI Usage Tools
| Tool | Description | Effort |
|---|---|---|
| Prompt Library / Templates | Curated prompts by role (manager, analyst, marketer, etc.) | Low |
| Prompt Optimizer / Rewriter | User pastes a rough prompt; tool suggests an improved version | Medium |
| AI Readiness Assessment | Quiz-style scoring of individual/team AI maturity — useful for enterprise lead-gen | Medium |

### 3.2 Skill & Learning Tools
| Tool | Description | Effort |
|---|---|---|
| AI Skill Gap Analyzer | User inputs role/goals; tool recommends relevant courses | Medium |
| ROI / Productivity Calculator | Estimates time/cost saved using AI in a given role — helps managers justify training budget | Low–Medium |

### 3.3 Team & Manager-Focused Tools
| Tool | Description | Effort |
|---|---|---|
| Use-Case Finder | Questionnaire suggesting AI tools/workflows suited to a specific job function | Medium |

### 3.4 Content & Utility Tools
| Tool | Description | Effort |
|---|---|---|
| AI Glossary / Terminology Tool | Searchable glossary of AI terms | Low |
| Model Comparison Tool | Compares GPT/Claude/Gemini etc. for specific use cases — positions platform as a neutral authority | Medium |

---

## 4. Summary

- **Now:** Build out full footer structure (Company, Product, Tools, Resources, Support, Legal, Social) and add the Prompt Evaluator as the first entry in the Tools column.
- **Next:** Expand the Tools column with ROI Calculator and AI Readiness Assessment — both are relatively low effort and speak directly to the management audience's need to justify AI adoption.
- **Later:** Build out the remaining tools based on user demand and platform growth (skill gap analysis, dashboards, glossary, model comparison).
